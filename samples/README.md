# micronaut-data-model sample ownership

[English](README.md) | [简体中文](README.zh-CN.md)

This module supplies entity, repository, and dialect model types. The runnable scenario is owned by [micronaut-data-jdbc](https://github.com/normlanguage/micronaut-data-jdbc/tree/main/samples) in its `samples/` directory; use that example to observe the behavior through the public API.

The module identity and pinned dependencies are defined in [module.norm](../micronaut/data/model/module.norm).
